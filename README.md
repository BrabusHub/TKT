# Une surprise pour Doudou

Site statique en français pour une escapade du 2 au 5 octobre 2026. Le dossier `dist` contient le site complet : ouvrir `index.html` pour le consulter, ou publier le contenu de ce dossier avec GitHub Pages.

La lettre se révèle avec le bouton d’accueil. Les trois onglets de programme fonctionnent à la souris et au clavier. Mise en page adaptée aux mobiles et animations réduites selon les préférences du système.

Les horaires sont ceux du cahier des charges, non vérifiés auprès des transporteurs. Le retour est prévu lundi après-midi, après Dinan.
